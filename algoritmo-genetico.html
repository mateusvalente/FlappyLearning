O cromossomo é uma lista de pesos

No jogo, cada indivíduo representa uma rede. Seu cromossomo contém [w₁, w₂, w₃, w₄, w₅, w₆]. A arquitetura permanece 2 → 2 → 1: o algoritmo modifica os pesos, não cria novos neurônios.

  1. Inicializar: gerar pesos aleatórios entre −1 e 1.
  2. Avaliar: deixar cada rede jogar e registrar quanto sobrevive.
  3. Ordenar: colocar os indivíduos com maior fitness primeiro.
  4. Preservar: copiar uma parcela dos melhores sem alteração.
  5. Explorar: incluir indivíduos com pesos inteiramente aleatórios.
  6. Reproduzir: combinar pesos dos pais e aplicar mutações até completar a população.

Laboratório de reprodução

Exemplo isolado de cruzamento e mutação de dois pais. Não é um treinamento completo: o filho precisaria jogar para receber um fitness.

Cada posição escolhe A ou B com 50% de chance. Depois, cada peso tem uma chance independente de mutação. Com taxa de 10%, nem todo filho terá uma mutação.

filho = cópia(paiA)
para cada peso i:
    se aleatório() ≤ 0,5: filho[i] = paiB[i]
para cada peso i:
    se aleatório() ≤ taxa:
        filho[i] += aleatório() × amplitude × 2 − amplitude

Após mutações, os pesos podem sair do intervalo inicial [−1, 1].

Os 30 lugares restantes são preenchidos por descendentes. Esses números valem para os parâmetros atuais e para uma geração totalmente avaliada. Os controles deste laboratório não alteram o jogo.

Como os pais são escolhidos aqui?

Em generateNextGeneration, os genomas estão ordenados pelo fitness. O código percorre pares começando pelos mais bem colocados e interrompe ao completar a população. Não implementa roleta nem torneio.

Desafio

Compare taxas 0%, 10% e 100%. Em qual delas os descendentes preservam mais características dos pais? Por que mutação alta pode prejudicar uma solução boa?
